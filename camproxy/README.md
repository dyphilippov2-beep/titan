# Сервер трансляций «Титан» для Trassir

Небольшая программа, которая показывает камеры арены родителям в приложении «Титан».
Она работает на любом компьютере в сети арены, сама входит в Trassir и отдаёт приложению только видео.
Логин и пароль Trassir остаются на этом компьютере и в приложение не попадают.

Одно видео с Trassir раздаётся сразу всем зрителям, поэтому 30 родителей у одной камеры
нагружают Trassir как один зритель. Ограничение одно: скорость отдачи интернета арены
(примерно 1–2 Мбит/с на каждого зрителя в «крупном» режиме, в сетке меньше).

## Что нужно

1. Компьютер в сети арены, который включён во время тренировок (Windows, Linux или мини-ПК). Подойдёт и сервер Trassir, если на нём можно поставить программы.
2. [Node.js](https://nodejs.org) версии 18 или новее.
3. В Trassir:
   - включён SDK / веб-сервер (Настройки → Сервер → «Веб-сервер» / «SDK», порт обычно 8080);
   - заведён отдельный пользователь, например `titan_view`, с правом **только просмотра** нужных 4 камер.

## Настройка

1. Скопируйте папку `camproxy` на компьютер в арене.
2. Сделайте копию `config.example.json` с именем `config.json` и заполните:

| Поле | Что писать |
|---|---|
| `trassir` | адрес Trassir в сети арены, например `https://192.168.1.10:8080` |
| `user`, `password` | пользователь Trassir только для просмотра |
| `viewKey` | длинная случайная строка (20+ символов). Её же вводят в приложении |
| `hours` | когда отдавать видео, например `06:30-23:00`. Пусто — всегда |
| `cams` | можно оставить пустым: тогда берутся все камеры, которые видит пользователь |

3. Запустите: `node server.js` (на Windows можно дважды щёлкнуть `start.bat`).
   В окне появится список камер — значит, вход в Trassir работает.

## Как сделать сервер доступным из интернета (без постоянного IP)

Приложение открывается по https, поэтому и сервер трансляций должен быть доступен по https.
Проще всего — **Cloudflare Tunnel**: компьютер сам выходит в интернет, роутер и постоянный IP не нужны.

1. Нужен свой домен (например `titan-hockey.ru`), подключённый к бесплатному аккаунту Cloudflare.
2. Поставьте на тот же компьютер программу `cloudflared` и создайте туннель
   (Cloudflare → Zero Trust → Networks → Tunnels → Create tunnel).
3. В туннеле добавьте адрес, например `cams.titan-hockey.ru`, который ведёт на `http://localhost:8090`.

Другой вариант — постоянный IP у провайдера, проброс порта на роутере и https через Caddy или nginx.

## Подключение в приложении

Войдите как администратор или руководитель → «Сегодня» → «Школа» → «Камеры арены»:

1. Адрес сервера: `https://cams.titan-hockey.ru`, ключ доступа: ваш `viewKey`.
2. «Загрузить камеры с сервера» → переименуйте камеры понятно для родителей → «Сохранить камеры».
3. Выберите, кто и когда смотрит. По умолчанию родитель видит камеры, только когда его группа на льду по расписанию.

## Что важно знать

- Ключ доступа защищает от случайных зрителей из интернета, но его видит каждый, у кого есть приложение.
  Окно «только во время тренировок своей группы» сейчас соблюдается в приложении. Строгая проверка
  на сервере появится вместе с настоящим входом по СМС.
- Если поменяли ключ на сервере, поменяйте его и в приложении.
- Проверка, что сервер жив: откройте `https://ваш-адрес/health`, должно быть `ok`.
